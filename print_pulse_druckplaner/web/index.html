Etsy-Verbindung

Die Zugangsdaten bleiben ausschließlich auf deinem Raspberry Pi. Deine bisherige Etsy-Home-Assistant-Integration wird nicht verändert.

Wähle eine URL auf einer Domain, die du selbst kontrollierst. Registriere sie zusätzlich in Etsy Developer. Die existierende Home-Assistant-Callback-Adresse nicht ändern. Die erste Anmeldung erfolgt über eine manuell eingefügte Redirect-URL; siehe Anleitung.

Einmalige Etsy-Autorisierung

1. Nach dem Speichern auf „Etsy-Autorisierung starten“ klicken. 2. Auf Etsy zustimmen. 3. Die vollständige Adresse aus der Browser-Adresszeile kopieren – auch wenn die Zielseite „Nicht gefunden“ anzeigt. 4. Hier einfügen. Den Code nicht an Dritte weitergeben.
